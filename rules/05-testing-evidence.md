# Testing and Evidence
- Derive tests from acceptance criteria and regression risk.
- Run the narrowest relevant test first, then broader checks.
- Report exact commands and whether they passed, failed, were skipped, or could not run.
- If no tests exist, state that and propose the smallest useful regression test.
- UI changes require screenshot comparison when the environment supports it.
- Never fabricate coverage percentages, performance gains, test output, or device validation.
