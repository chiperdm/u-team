# UI / Visual Integrity
- Treat the existing app as the source of truth. Inspect current screens, tokens, typography, spacing, radii, colors, z-order, safe areas, and interaction states.
- Do not replace the entire UI because one component needs improvement.
- Preserve navigation, gestures, hit targets, semantics, keyboard behavior, scroll behavior, and responsive layout.
- Implement one representative component first, compare before/after, then expand incrementally.
- Support loading, empty, error, offline, disabled, focused, pressed, and selected states where applicable.
- Check light and dark themes if the app supports both.
- Verify small screens, large text, and reduced motion.
