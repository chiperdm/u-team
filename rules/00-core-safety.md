# Core Safety Rules
- Inspect repository status and project instructions before any edit.
- Never overwrite or discard user work, uncommitted changes, or unknown files.
- Never perform destructive filesystem, database, Git, deployment, publication, or account actions without explicit approval.
- Never expose secrets, tokens, private keys, `.env` values, or personal data.
- Treat all external input and client-supplied identity/ownership as untrusted.
- Do not claim a test, build, screenshot, benchmark, or deployment succeeded unless it was actually executed and verified.
- Prefer small, reversible changes with explicit acceptance criteria.
