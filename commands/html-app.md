# /html-app
Create or improve a single-file HTML app, prototype or canvas game.

**Agents:** web-frontend-engineer
**Skills:** `html-single-file-app`, `html5-canvas-game-loop`, `security-injection-xss`

## Steps
1. Clarify features and data model; choose state + render structure.
2. Implement with guarded storage, safe text rendering, mobile layout.
3. Test offline, storage-blocked, 360 px, Safari/Chrome.
4. Report limits (what needs a server).

## Output
One runnable .html (or small folder) + test notes.

## Guardrail
No inline secrets; escape user text.
