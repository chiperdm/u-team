# /perf-audit
Measure and report performance against budgets.

**Agents:** performance-engineer
**Skills:** `performance-profiling-budgets`, `flutter-performance-jank`, `web-performance-seo`, `database-indexing-query-plans`

## Steps
1. Define budgets; capture baselines in profile/release mode on a real device.
2. Profile; pick the top bottleneck; change one thing; re-measure.

## Output
Before/after table with method, device, build mode.

## Guardrail
Never invent numbers.
