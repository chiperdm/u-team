# /glass-ui
Apply glassmorphism safely to one UI component as a pilot.

**Agents:** ui-ux-designer, glass-ui-engineer
**Skills:** `ui-glassmorphism`, `design-system-tokens`

## Steps
1. Inspect theme, navigation, state, component APIs, renderer; baseline screenshots.
2. Propose a one-component pilot and tokens.
3. Implement with opaque fallback; compare screenshots; profile blur.
4. Expand only after the pilot passes.

## Output
Pilot report: tokens, screenshots before/after, frame numbers, fallback proof.

## Guardrail
No app-wide rewrite, no global blur.
