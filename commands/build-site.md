# /build-site
Build a complete responsive HTML/CSS/JS website from a short brief.

**Agents:** web-frontend-engineer, design-reviewer
**Skills:** `html-site-builder`, `css-modern-layout`, `web-performance-seo`, `web-motion-scroll`, `web-liquid-glass-css`

## Steps
1. Capture or assume: purpose, audience, primary action, tone, languages; state assumptions.
2. Pick a design direction; define tokens; start from `assets/starter.html`.
3. Build sections with real copy; add dark mode, reduced motion, optional glass.
4. Run the deliverable checklist (viewports, keyboard, validator, Lighthouse).
5. Deliver files + how to open/deploy.

## Output
Site files, checklist results, placeholders list.

## Guardrail
No fake testimonials/stats, no secrets in HTML.
