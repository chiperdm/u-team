# /design-review
Read-only visual and UX critique with a prioritized fix list.

**Agents:** design-reviewer, accessibility-reviewer
**Skills:** `ui-design-review`, `design-system-tokens`, `ui-accessibility`

## Steps
1. Collect screenshots (phone/desktop, light/dark, large text).
2. State intent and primary action.
3. Walk the checklist; rank findings; propose a pilot and token changes.

## Output
Findings table (severity, fix values, effort), keep-list, top 3 changes.
