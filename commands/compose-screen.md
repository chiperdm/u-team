# /compose-screen
Build or refactor a Jetpack Compose screen with state hoisting, motion and accessibility.

**Agents:** compose-ui-engineer, kotlin-engineer
**Skills:** `kotlin-compose-foundations`, `compose-motion-gestures`, `android-architecture-room`, `kotlin-coroutines-flow`

## Steps
1. Inspect existing architecture, theme and navigation.
2. Define UiState/events; implement stateless composables + route-level composable.
3. Add previews (light/dark/font scale) and Compose tests.
4. Check recomposition and frame timing.

## Output
Files, previews, test results, performance notes.

## Guardrail
Follow the project architecture; no new libraries without review.
