# Workflow: Release Readiness
1. Freeze scope and confirm release target.
2. Check clean/known Git state.
3. Run analyzers, tests, and production build.
4. Verify permissions, secrets, signing, dependency advisories, API compatibility, and migrations.
5. Verify artifact version and checksum/signature.
6. Review release notes and rollback plan.
7. Obtain explicit approval before publication/deployment.
