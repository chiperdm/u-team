# Workflow: Feature Delivery
1. Requirements analyst defines scope and acceptance criteria.
2. Architect maps dependencies and risks.
3. Orchestrator assigns exclusive file ownership.
4. Engineers implement bounded slices.
5. QA adds regression and failure-path tests.
6. Security reviews sensitive boundaries.
7. Code reviewer inspects diff.
8. Final verifier checks evidence and acceptance criteria.
9. Orchestrator reports changes, tests, risks, and uncompleted items.
