# Workflow: HTML Site Delivery
1. `product-analyst`: brief (purpose, audience, primary action, tone, languages); assumptions stated.
2. `ui-ux-designer`: design direction + tokens (`design-system-tokens`).
3. `web-frontend-engineer`: build from `html-site-builder/assets/starter.html`; real copy; dark mode; reduced motion.
4. Optional glass/motion: `web-liquid-glass-css`, `web-motion-scroll` (progressive enhancement).
5. `performance-engineer`: Lighthouse mobile run; fix LCP/CLS/INP offenders (`web-performance-seo`).
6. `accessibility-reviewer` + `design-reviewer`: keyboard, contrast, hierarchy, "generic AI look" tells.
7. `release-engineer`: hosting plan (static host or Render Static Site); domain, HTTPS, caching.
8. `final-verifier`: deliverable checklist evidence; report placeholders honestly.
