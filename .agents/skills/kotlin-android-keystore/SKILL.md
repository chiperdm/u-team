# Android Keystore

- Generate non-exportable keys inside `AndroidKeyStore` (`KeyGenParameterSpec`, `AES/GCM/NoPadding`, 256-bit). Never hardcode keys or derive them from constants.
- **New random IV for every encryption** (GCM, 12 bytes); store IV next to the ciphertext. Reusing an IV with the same key breaks GCM.
- Optional `setUserAuthenticationRequired(true)` for high-value keys; handle `KeyPermanentlyInvalidatedException` (biometric enrollment changed) by re-provisioning.
- StrongBox (`setIsStrongBoxBacked`) when available, with fallback to the TEE-backed key on `StrongBoxUnavailableException`.
- `androidx.security:security-crypto` (EncryptedSharedPreferences) has been deprecated: verify its current status before using it, and prefer a Keystore-wrapped key with DataStore/your own storage.
- Backups: decide explicitly (`android:allowBackup`, `dataExtractionRules`); Keystore keys are not restored to another device, so encrypted data restored from backup becomes unreadable: exclude it or handle re-login.
- Do not invent protocols: for message E2EE use a vetted library/protocol and have security review it.

## Minimal AES-GCM wrapper
```kotlin
object Vault {
    private const val ALIAS = "app_data_key"
    private fun key(): SecretKey {
        val ks = KeyStore.getInstance("AndroidKeyStore").apply { load(null) }
        (ks.getKey(ALIAS, null) as? SecretKey)?.let { return it }
        val spec = KeyGenParameterSpec.Builder(ALIAS, KeyProperties.PURPOSE_ENCRYPT or KeyProperties.PURPOSE_DECRYPT)
            .setBlockModes(KeyProperties.BLOCK_MODE_GCM).setEncryptionPaddings(KeyProperties.ENCRYPTION_PADDING_NONE)
            .setKeySize(256).build()
        return KeyGenerator.getInstance(KeyProperties.KEY_ALGORITHM_AES, "AndroidKeyStore").apply { init(spec) }.generateKey()
    }
    fun encrypt(plain: ByteArray): ByteArray {
        val c = Cipher.getInstance("AES/GCM/NoPadding").apply { init(Cipher.ENCRYPT_MODE, key()) }   // IV generated by the Keystore
        return c.iv + c.doFinal(plain)                                                               // 12-byte IV prefix
    }
    fun decrypt(blob: ByteArray): ByteArray {
        val c = Cipher.getInstance("AES/GCM/NoPadding").apply { init(Cipher.DECRYPT_MODE, key(), GCMParameterSpec(128, blob.copyOfRange(0, 12))) }
        return c.doFinal(blob, 12, blob.size - 12)
    }
}
```
(Compile and test on a device; wrap `KeyPermanentlyInvalidatedException`/`InvalidKeyException` into a re-provision path.)

## Verify
Unit-test the format on-device (instrumented): round trip, tamper one byte -> `AEADBadTagException`, two encryptions of the same plaintext differ; reinstall/backup restore behavior documented; no key material in logs.

## Pitfalls
- Caching the decrypted key bytes (defeats non-exportability): use the `SecretKey` handle.
- Encrypting with a user-supplied IV or a counter you may reuse.
- Assuming Keystore data survives device migration.
